# Слова — оболочка на GitHub Pages

Эта папка делает из веб-приложения «Слова» обычное приложение на телефоне: значок на экране «Домой», полноэкранный режим, без баннера Google.

## Установка (один раз)
1. В Google: создайте **новую таблицу** → Расширения → Apps Script. Вставьте код из `Code.gs`, создайте файл **Index** (HTML) и вставьте код из `Index.html`.
2. Развернуть → Новое развёртывание → Веб-приложение: «Выполнять от моего имени», доступ «Все». Скопируйте адрес.
3. Обновите таблицу: появится меню «Слова» → «Показать ссылку и ключ».
4. github.com → **New repository** (например `words`), Public → загрузите все файлы из этой папки → Settings → Pages → Branch `main`, `/ (root)`.
5. Откройте `https://имя.github.io/words/` на телефоне, вставьте ссылку из таблицы. На iPhone: Safari → «Поделиться» → «На экран “Домой”».

Этот проект хранит свои данные отдельно от USMLE Progress, даже если лежит на том же сайте GitHub.

## Виджет на экран блокировки
В приложении: «Ещё» → «Виджет на экран блокировки» — там пошаговая инструкция и кнопка «Скопировать код виджета» (нужно бесплатное приложение Scriptable).

## Обновления
Когда вы меняете файлы на GitHub (вместе с числом в `version.json`) или публикуете новую версию в Apps Script, приложение само подтягивает новую версию.
