# USMLE Progress — GitHub-оболочка

Эта папка убирает баннер Google и позволяет установить сайт как приложение.

## Выложить (один раз, ~3 минуты)
1. github.com → **New repository** (например `usmle`), Public.
2. **Add file → Upload files** → перетащи ВСЕ файлы из этой папки (index.html, sw.js, manifest.webmanifest и 4 иконки) → Commit.
3. **Settings → Pages** → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту адрес будет `https://ИМЯ.github.io/usmle/`.

## Подключить
1. Открой сайт → раздел **«Ещё»** → блок «Приложение» → впиши этот GitHub-адрес → «Сохранить адрес».
2. В таблице: меню **📈 USMLE Progress → Открыть отчёт** — там будет ссылка для приложения. Открой её на каждом устройстве один раз.

## Установить как приложение
- **iPhone/iPad:** только в Safari → «Поделиться» → «На экран Домой».
- **Android / компьютер (Chrome, Edge):** кнопка «Скачать как приложение» в разделе «Ещё».

Адрес и ключ хранятся в самой ссылке после знака `#` — он никогда не отправляется на сервер GitHub.
Не показывай адресную строку на скриншотах: в ней ключ доступа.
