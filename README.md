# USMLE Progress — оболочка на GitHub Pages

Эта папка делает из веб-приложения Google обычное приложение на телефоне: значок на экране «Домой», полноэкранный режим, офлайн-экран, уведомления.

## Установка (один раз, около 3 минут)
1. github.com → **New repository** (например, `usmle`), Public.
2. **Add file → Upload files** → перетащите все файлы из этой папки (index.html, sw.js, manifest.webmanifest, **version.json**, иконки) → Commit.
3. **Settings → Pages** → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://имя.github.io/usmle/`.

## Подключение
1. В таблице: меню **USMLE Progress → Показать ссылку и ключ** → скопируйте ссылку для установки.
2. Откройте её на телефоне. Ключ и адрес запомнятся, и можно ставить значок на экран «Домой»:
   - **iPhone/iPad:** Safari → «Поделиться» → «На экран “Домой”».
   - **Android / компьютер (Chrome, Edge):** значок «Установить» в адресной строке.

## Как приходят обновления
Приложение обновляется само, переустанавливать ничего не нужно.

- **Приложение (Google).** Когда вы публикуете новую версию в Apps Script (Развернуть → Управление развёртываниями → карандаш → Новая версия), открытое приложение через несколько секунд само перезапускается в спокойный момент: не прерывает ввод, открытое окно или сохранение.
- **Оболочка (этот сайт).** Если вы заменили файлы на GitHub, приложение само замечает новую версию (по файлу `version.json`), показывает «Вышла новая версия — обновляю…» и перезагружается. Проверка идёт при открытии, при возвращении в приложение и раз в полчаса.
- **Вручную.** В приложении: «Ещё» → «Проверить обновления».
- **Старые установки** (поставленные до этого обновления) подхватят новую версию после перезапуска приложения; дальше всё идёт автоматически.

**Выпуская новую версию оболочки:** вместе с `index.html` меняйте число в `version.json` (оно должно совпадать с `WRAP_V` в начале скрипта `index.html`, в архиве они уже совпадают).

## Поделиться статистикой с другом
«Ещё» → «Поделиться статистикой» → «Создать ссылку». Друг видит только цифры и графики Anki и UWorld, страница обновляется сама. Заметки, планер, ошибки, First Aid, NBME и ключи не показываются.

- Ссылка вида `https://имя.github.io/usmle/?share=…` работает через ваш сайт, поэтому без баннера Google. Для этого адрес сайта должен быть указан в «Ещё» → «Скачать как приложение».
- «Создать новую ссылку» сразу отключает старую, «Отключить доступ» закрывает страницу совсем.
- Ссылка привязана к вашему развёртыванию Apps Script. Публикуйте обновления как «Новая версия» того же развёртывания; если создадите новое развёртывание, ссылки нужно создать заново.

## Уведомления (за 10 минут до события и вовремя)
1. В приложении: «Ещё» → «Планер» → включите напоминания и разрешите уведомления.
2. На iPhone: уведомления работают только из значка на экране «Домой» (iOS 16.4 и новее).
3. Если уведомления не приходят: настройки телефона → Уведомления → USMLE Progress.
